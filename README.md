Kitty Cat Simulator

Technical Manager & Lead Developer: Hafiz Saad Khawar
Company: CCTechSolution (Crystal Continental Trading Ltd)

Kitty Cat Simulator is a Unity-based simulation game where players explore, care for, and interact with adorable virtual cats in a richly animated environment.

Overview

Engine: Unity 6.0 (latest stable version)

Genre: Simulation / Casual

Platforms: Android (iOS coming soon)

Version: 1.1

SDK/API: Latest Android SDK 35 + Google Play In-App Billing
